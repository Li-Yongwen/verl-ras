# 如何验证 generate_sequences 输出维度

## 概述

当 worker 故障恢复后，需要验证 `generate_sequences` 的输出维度是否正确。可以通过与备份的 `gen_batch_output_ori` 进行比较来验证。

## DataProto 的维度结构

`DataProto` 包含三个主要部分：

1. **`batch`** (TensorDict): 包含所有 tensor 数据
   - 每个 tensor 的 `shape[0]` 是 batch size
   - `batch.batch_size[0]` 是 batch size

2. **`non_tensor_batch`** (dict): 包含所有非 tensor 数据（numpy array 等）
   - 每个 numpy array 的 `shape[0]` 是 batch size

3. **`meta_info`** (dict): 元信息

## 验证方法

### 方法1: 使用验证函数（推荐）

我已经创建了验证函数 `validate_output_dimensions`，会自动比较所有维度：

```python
from verl.trainer.ppo.validate_output_dimensions import validate_output_dimensions, print_data_proto_summary

# 打印摘要信息
print_data_proto_summary(gen_batch_output, "恢复后的输出")
print_data_proto_summary(gen_batch_output_ori, "原始备份")

# 验证维度
result = validate_output_dimensions(gen_batch_output, gen_batch_output_ori, verbose=True)

if not result['is_valid']:
    print(f"发现 {len(result['errors'])} 个错误")
    for error in result['errors']:
        print(f"  - {error}")
```

### 方法2: 手动检查关键维度

```python
# 1. 检查 batch size
len_output = len(gen_batch_output)  # 使用 __len__
len_ori = len(gen_batch_output_ori)
print(f"Batch size: output={len_output}, original={len_ori}")

# 2. 检查 batch.batch_size
print(f"batch.batch_size: output={gen_batch_output.batch.batch_size}, original={gen_batch_output_ori.batch.batch_size}")

# 3. 检查关键 tensor 的 shape
key_tensors = ['input_ids', 'attention_mask', 'responses', 'prompts']
for key in key_tensors:
    if key in gen_batch_output.batch and key in gen_batch_output_ori.batch:
        shape_out = gen_batch_output.batch[key].shape
        shape_ori = gen_batch_output_ori.batch[key].shape
        print(f"{key}: output={shape_out}, original={shape_ori}, match={shape_out == shape_ori}")

# 4. 检查 non_tensor_batch 的 shape
for key in gen_batch_output.non_tensor_batch.keys():
    if key in gen_batch_output_ori.non_tensor_batch:
        arr_out = gen_batch_output.non_tensor_batch[key]
        arr_ori = gen_batch_output_ori.non_tensor_batch[key]
        if isinstance(arr_out, np.ndarray) and isinstance(arr_ori, np.ndarray):
            print(f"{key}: output={arr_out.shape}, original={arr_ori.shape}, match={arr_out.shape == arr_ori.shape}")
```

## 需要检查的关键维度

### 1. Batch Size（最重要）

```python
# 方法1: 使用 __len__
assert len(gen_batch_output) == len(gen_batch_output_ori), \
    f"Batch size mismatch: {len(gen_batch_output)} != {len(gen_batch_output_ori)}"

# 方法2: 使用 batch.batch_size
assert gen_batch_output.batch.batch_size == gen_batch_output_ori.batch.batch_size, \
    f"batch.batch_size mismatch: {gen_batch_output.batch.batch_size} != {gen_batch_output_ori.batch.batch_size}"
```

### 2. Tensor Shapes

检查所有 tensor 的完整 shape（包括 batch 维度和序列维度）：

```python
for key in gen_batch_output.batch.keys():
    if key in gen_batch_output_ori.batch:
        shape_out = gen_batch_output.batch[key].shape
        shape_ori = gen_batch_output_ori.batch[key].shape
        assert shape_out == shape_ori, \
            f"Tensor '{key}' shape mismatch: {shape_out} != {shape_ori}"
```

### 3. Non-tensor Shapes

检查所有 non_tensor 数据的 shape：

```python
for key in gen_batch_output.non_tensor_batch.keys():
    if key in gen_batch_output_ori.non_tensor_batch:
        arr_out = gen_batch_output.non_tensor_batch[key]
        arr_ori = gen_batch_output_ori.non_tensor_batch[key]
        if isinstance(arr_out, np.ndarray) and isinstance(arr_ori, np.ndarray):
            assert arr_out.shape == arr_ori.shape, \
                f"Non-tensor '{key}' shape mismatch: {arr_out.shape} != {arr_ori.shape}"
```

## 常见问题

### 问题1: Batch size 不匹配

**原因**: 
- Worker 数量变化导致数据分片数量变化
- 部分 worker 失败导致数据丢失

**检查**:
```python
print(f"Output batch size: {len(gen_batch_output)}")
print(f"Original batch size: {len(gen_batch_output_ori)}")
print(f"Worker group world_size: {worker_group_to_use.world_size}")
```

### 问题2: Tensor shape 不匹配

**原因**:
- 序列长度不同（如果使用了不同的 worker）
- Padding 不一致

**检查**:
```python
# 检查序列长度
if 'input_ids' in gen_batch_output.batch:
    seq_len_out = gen_batch_output.batch['input_ids'].shape[1]
    seq_len_ori = gen_batch_output_ori.batch['input_ids'].shape[1]
    print(f"Sequence length: output={seq_len_out}, original={seq_len_ori}")
```

### 问题3: 缺少或多余的 keys

**原因**:
- Worker 返回的数据结构不同
- 某些字段未正确传递

**检查**:
```python
output_keys = set(gen_batch_output.batch.keys())
ori_keys = set(gen_batch_output_ori.batch.keys())
missing = ori_keys - output_keys
extra = output_keys - ori_keys
if missing:
    print(f"Missing keys: {missing}")
if extra:
    print(f"Extra keys: {extra}")
```

## 在代码中的使用

验证代码已经集成到异常处理中（`verl/trainer/ppo/ray_trainer.py`），会在 worker 恢复后自动执行：

```python
# 使用活着的worker继续推理
gen_batch_output = worker_group_to_use.generate_sequences(gen_batch_output)

# 验证输出维度是否正确（与备份比较）
from verl.trainer.ppo.validate_output_dimensions import validate_output_dimensions, print_data_proto_summary

print_data_proto_summary(gen_batch_output, "恢复后的 gen_batch_output")
print_data_proto_summary(gen_batch_output_ori, "原始备份 gen_batch_output_ori")

validation_result = validate_output_dimensions(
    gen_batch_output, 
    gen_batch_output_ori, 
    verbose=True
)

if not validation_result['is_valid']:
    print(f"[ERROR] 输出维度验证失败！")
    # 处理错误...
```

## 验证函数返回的详细信息

`validate_output_dimensions` 返回一个字典，包含：

```python
{
    'is_valid': bool,              # 是否所有维度都匹配
    'batch_size_match': bool,      # batch size 是否匹配
    'batch_size': (int, int),      # (output, original)
    'tensor_shapes_match': dict,   # 每个tensor的shape是否匹配 {key: bool}
    'non_tensor_shapes_match': dict, # 每个non_tensor的shape是否匹配 {key: bool}
    'errors': list,                # 错误信息列表
}
```

## 总结

**关键检查点**：
1. ✅ `len(gen_batch_output)` == `len(gen_batch_output_ori)` - batch size
2. ✅ `gen_batch_output.batch.batch_size` == `gen_batch_output_ori.batch.batch_size`
3. ✅ 所有 tensor 的 `shape` 完全匹配
4. ✅ 所有 non_tensor 的 `shape` 完全匹配
5. ✅ 所有 keys 都存在（没有缺失或多余）

如果以上都通过，说明维度是正确的！
